# C 站 · 工程与安装行业 Demo（装饰工程）

> **本项目是一套「行业样张」，不是真实企业站。** 品牌「恒川装饰工程（示例）」、电话、地址、资质、案例、数据全部为虚构示例内容，用于谈单时直接甩链接给客户看。页脚已按合规要求标注「本网站为演示样例，非真实企业」。

| 项 | 值 |
|---|---|
| 行业方向 | 工程与安装类（装饰工程 / 装修公司） |
| 页面 | 5 页：首页 / 业务服务 / 案例业绩 / 资质专页 / 联系我们 |
| 行业专属模块 | 首页「施工前后对比」区、资质专页「证书展示位（可点击放大）」+ 资质清单 |
| 技术 | 纯静态 HTML + CSS + 原生 JS，零框架、零构建、零付费依赖、零外部请求 |
| 线上链接 | 见文末「线上访问」 |

## 一、如何打开

**本地一条命令**（需要 Node.js 18 及以上，本机为 v22.13.0）：

```bash
node serve.mjs 4175
```

浏览器打开 <http://localhost:4175/>。Windows 下也可双击 `start.cmd`。

**线上访问**：见文末「线上访问」一节（部署后填入）。

## 三、页面与模块要点

| 页面 | 关键模块 |
|---|---|
| 首页 | 首屏一句话说明 + 双行动入口 + 实景主视觉；数据条（标注示例数据）；**施工前后对比区**；四类业务（带图卡）；六步流程编号列表；客户引言（标注示例评价）；CTA |

## 四、素材与合规

- 11 张图全部来自 Pexels（Pexels License，免费商用、无需署名），逐张人工过目记录见 `docs\素材来源与许可.md`；**没有使用 AI 生成图**。
- 全站不加载任何外部字体与第三方脚本，无外部网络请求。
- 页面文案不含绝对化用语与效果承诺；装修行业不作「零增项」「绝对环保」一类承诺。
- 资质证书位为**明确标注「示例占位 · 非真实证书」**的占位图，未编造真实格式的资质编号。
- 页脚备案位写「备案号：待备案」，不留空白。
- 电话用真实号段格式（0595-2216-6688），**但八处可见位置都加了「（示例，请勿拨打）」标注**，避免客户误拨到陌生人；不改成 000-0000 之类占位写法。

## 五、已知限制

1. **图片是图库示意照**，不是客户实拍；「施工前后对比」两张图也不是同一户型的实拍，页面已注明。交付客户时必须替换。
2. **案例说明、金额、工期、人员数、资质等级均为示例数据**，页面各处已标注，不能当真实案例引用。
3. **表单不接后端**，提交只在前端做校验与提示，不会真的发出去；正式上线需在 `assets\js\site.js` 的提交分支接接口。
4. **证书位与资质清单是版式示范**，真实证书未提供前不得用于投标或对外承诺。
5. **未做备案与域名**：本 Demo 走境外免费托管，境内访问速度需实测；正式客户站按《交付SOP.md》走。
6. **深色模式跟随系统偏好**，不是可切换的开关。

## 六、换客户要改哪些地方

1. `assets\css\base.css` 的 `:root`（主色、强调色、灰阶）与其下的深色模式变量；
2. 五个 HTML 的 `<title>`、`<meta description>`、`theme-color`、品牌名与页脚；
3. `assets\img\` 全部图片（换图后同步改 `alt` 与 `data-search` 检索词）；
4. `qualifications.html` 的证书位与资质清单；
5. 各页的示例数据与「（示例）」标记 —— 真实客户站才去掉 R5 示范标识；
6. `docs\` 三份文档按客户信息回填。

## 注意事项 / 未解决问题

- **素材是图库示意照，不是客户实拍**：「施工前后对比」两张也不是同一户型的实拍，页面已注明；交付客户前必须替换成客户自有素材。
- **案例、金额、工期、人员数、资质等级全是示例数据**，页面各处已标注，不得当真实案例引用或用于投标。
- **表单不接后端**，正式上线要在 `site.js` 的提交分支接接口，并补真实隐私政策全文。
- **资质证书位是版式示范**，真实证书未提供前不得对外承诺资质。
- **`hidden` 属性的老坑仍在**：导航靠 `<nav hidden>` + `@media (min-width: 641px) { .nav[hidden]{display:flex} }` 覆盖。删掉那条 CSS，桌面导航会整体消失 —— 改样式时别动它。
- **境内取图链路**：本机不能直连 Pexels 搜索页与图片源站，图片经 `images.weserv.nl` 代理取回再转 WebP；换客户时按 `docs\素材来源与许可.md` 里写的同一流程重取。

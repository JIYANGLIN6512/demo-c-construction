# 交付 SOP（C 站 · 装饰工程行业 Demo）

> 依据：《行业 Demo 验收标准 v1.1》第 5.1、5.2 节正式口径。**阶段 Gate 与工时口径均引用该标准，不另定标准。**
> 适用范围：把行业 Demo 改成客户真实站，或从零建同类站。Demo 本身只做展示与谈单，不接真实客户业务。

## 一、五阶段流程

| 阶段 | 做什么 | 产出物 | 责任 |
|---|---|---|---|
| 1 需求确认 | 发《需求表.md》，收素材与文案 | 填好的需求表 | 策划 / 客户 |
| 2 方案与素材 | 改文案、换图、换配色；素材缺项先催 | Demo 站 + 素材来源清单 | 开发 |
| 3 自测与取证 | 浏览器逐页自测 + Lighthouse，出截图与报告 | 自测记录、截图、报告 | 开发 |
| 4 客户验收 | 客户书面确认（验收单或群内回复） | 确认记录 + 最终截图 | 策划 → 复核 |
| 5 上线 | 备案或境外托管，配置域名与 HTTPS | 可访问链接 | 开发 |

**进入「4 客户验收」的前置条件（标准 5.1 原文口径）：**
> AC-D01、AC-D11、AC-D14、AC-D15 四条全部满足，且由开发提供实测证据（四页互跳无失效、375px 无横向滚动、性能分数报告、表单空提交与正常提交各一次的结果）。

要点三条：

1. 「自测通过」这个词**不得再作为阶段 Gate**，必须换成上面四条可判断项。
2. 开发提供的是**证据**，不是「合格」结论；结论由复核岗下。
3. 这四条只覆盖「能不能交给客户看」的最低门槛；完整 20 条在最终交付前全查。

## 二、工时口径（标准 5.2 原文口径）

> **① 口径分层：** 工时表必须分两列 —— 「纯改稿工时」与「对客交付总工时」。
> **② 对客报价只能用总工时：** 纯改稿实测（T-12 的 18 分钟，含记录 25 分钟）**不得作为对客报价依据**，也不得对外承诺「当天交付」。对客口径为 **4–6 小时**（`[估算]`，T-12 记录支持「4 小时站得住」，前提是素材客户自备）。
> **③ 回填责任与裁定：** 回填由开发执行并提供原始记录位置；「该工时是否可作为报价依据」由复核岗裁定，不由开发自判。

**本表工时基于素材齐备前提，素材需我方寻找或拍摄时，工时另行计算。**

| 阶段 | 纯改稿工时（开发实测） | 对客交付总工时（估算口径） | 备注 |
|---|---|---|---|
| 1 需求确认 | —— | 0.5–1 h | 含沟通与填表 |
| 2 方案与素材（文案 + 换图 + 换配色） | 见《自测记录.md》 | 1.5–2.5 h | 素材自备时；缺素材另计 |
| 3 自测与取证（双视口 + Lighthouse + 截图） | 见《自测记录.md》 | 0.5–1 h | |
| 4 客户验收与修改 | —— | 1–1.5 h | 按修改轮次计 |
| 5 上线（域名 / 备案 / 托管） | —— | 0.5–1 h | 备案审批时长不含在内 |
| **合计** | **见自测记录** | **4–6 h `[估算]`** | 备案等待时间不计入 |

## 三、素材处理流程（工程类专属）

1. 图源只用免费可商用图库（CC0 / Unsplash / Pexels）或客户自有素材；**不用来源不明、带水印、含第三方品牌标识的图**。
2. 逐张人工过目，不看文件名看图；每张都要能回答「这张和这个行业什么关系」；不跨行业混搭（装修站不放机械厂房、不放风景、不放城市天际线）。
3. 记录图片来源 URL 与许可，随站交付（见《素材来源与许可.md》）。
4. 资质证书位在客户未提供真实证书前，一律用**明确标注「示例占位 · 非真实证书」**的占位图，**不编造真实格式的资质编号**。

## 四、已知风险

| 风险 | 说明 | 处置 |
|---|---|---|
| 图源与行业错位 | 检索词对、图不对是行业 Demo 最致命的问题，触红线即整站返工 | 逐张过目，写进素材来源清单；必要时重取 |
| 境外托管在境内访问不稳 | 客户第一次打开是手机，访问慢直接掉印象 | 图片本地化（已转 WebP）、页面零外部依赖；必要时改境内主机并备案 |
| 演示站被误认为真实企业 | 合规风险高于收益 | 页脚一行小字「本网站为演示样例，非真实企业」≥12px、同色同字体；品牌名带「（示例）」；不加弹窗与横幅 |
| 表单收集个人信息 | 受《个人信息保护法》约束 | 演示站表单不接后端并显著标注不发送；站内保留隐私说明段落 |
| 备案周期不可控 | 管局法定时限 20 个工作日 | 起步期先上境外免费托管，备案单列待办，不阻塞交付 |

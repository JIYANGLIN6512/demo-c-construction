- **Pexels License**：可免费用于商业与非商业用途，无需署名；不得原样转售，不得作为图库再分发，不得用于商标或可能误导用途的人物形象。站内 11 张图均为该许可。
- **字体**：全站只用系统字体栈（`-apple-system / Segoe UI / PingFang SC / Microsoft YaHei` 与衬线 `Songti SC / SimSun / Noto Serif CJK SC`），**未加载任何外部字体文件**，不涉及字体授权。
